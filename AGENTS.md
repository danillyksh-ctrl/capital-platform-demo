# Капитал

Самостоятельный демонстрационный кабинет на Laravel 13, PHP 8.4, Vue 3.5+, Inertia 2 и Vite 7.
Серверная валидация, роли и блокировки обязательны. Не переносите контроль доступа в клиент.
Все демонстрационные данные должны быть вымышленными. Секреты и базы данных не коммитить.
PHPDoc и комментарии к сложной логике пишите на русском; идентификаторы на английском.
Проверки: `php artisan test`, `vendor/bin/pint --test`, `npm run build`.
