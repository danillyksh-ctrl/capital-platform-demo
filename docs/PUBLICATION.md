## Mailpit

Реальная SMTP-доставка проверена скриптом `scripts/check-mailpit.php`:

1. Создаётся отдельный вымышленный пользователь с уникальным адресом `.test`.
2. Laravel отправляет настоящее уведомление подтверждения через SMTP.
3. Через Mailpit проверяется наличие ссылки `/verify-email/` с подписью.
4. Password broker отправляет настоящее уведомление восстановления.
5. Через Mailpit проверяется ссылка `/reset-password/` с ожидаемым адресом.
6. Созданный проверочный аккаунт и запись reset token удаляются. Содержимое токенов и пароли не выводятся в журнал.

Сценарий прошёл на локальном Mailpit 1.34.0 и в первом Docker-задании с контейнерным Mailpit. Контрольная контейнерная проверка также прошла, её результат указан в таблице выше. Реальных получателей и внешней отправки почты не было.
